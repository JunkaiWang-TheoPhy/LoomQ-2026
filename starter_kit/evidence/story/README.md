# Story World 交付格式

本目录是最终提交中的故事与演示材料包。评委无需访问开发对话，直接从这些文件阅读和复核作品。

| 文件 | 格式 | 用途 |
| --- | --- | --- |
| `Story.PR` | PR story text | 完整女频式第三人称故事稿 |
| `Quantum_Atlas_Story.docx` | DOCX | 可编辑、带插图和页眉页脚的排版稿 |
| `Quantum_Atlas_Story.pdf` | PDF | 固定版式阅读稿 |
| `GAME_CATALOG.md` | Markdown | 游戏清单与主游戏路径 |
| `DEMO_GUIDE.md` | Markdown | 五分钟演示脚本 |
| `TECHNICAL_REPORT.md` | Markdown | API、证据链和边界 |
| `Quantum_Atlas_Demo.pptx` | PPTX | 评委演示 slides |

主游戏固定在 `starter_kit/web/game.html`。故事主线是《零点之后的观测者》，主角是宇航站观察者沈遥，第一案是《她的第八十年》。

DOCX、PDF 和 PPTX 使用仓库中的原创 `quantum-world-journey.png` 与 `quantum-atlas-map.png`。这些图片只承担叙事和导航作用，不参与量子结果判定。
