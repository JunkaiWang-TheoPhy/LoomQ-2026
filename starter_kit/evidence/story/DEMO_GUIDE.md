# Quantum Atlas 评委演示文档

## 演示目标

让评委在五分钟内看到一条完整的证据路径：一个没有量子背景的人先提出判断，系统让他只改变一个变量，返回真实实验结果，再把结论限制在证据能够支持的范围内。随后，评委可以打开五个地图案件，看到故事如何继续使用同一套实验协议。

## 启动

```bash
cd starter_kit
python3 -m loomq.web --host 127.0.0.1 --port 8767
```

主游戏地址：`http://127.0.0.1:8767/game.html`
技术实验室地址：`http://127.0.0.1:8767/`

## 五分钟演示脚本

### 0:00—0:40　进入观测站

打开 `game.html`。说明沈遥是宇航站观察者，故事从她的第八十年开始。此时案件板显示五个案件，但它们处于待解锁状态。

观察重点：

- 没有量子背景也能理解目标；
- 页面先给问题，再出现 H 和 CX；
- 故事插画不是实验结果。

### 0:40—1:40　收集调查方法

用键盘方向键或 WASD 移动，按 `E` 调查观测站中的四件物品。四件物品分别代表状态、可能性、重复观测和单变量对照。

观察重点：

- 角色移动有碰撞边界；
- 每条教学信息都对应后续实验动作；
- 进度系统不会把“看过文案”当成“已经得到证据”。

### 1:40—2:40　主线实验

在分岔原野的 A/B 装置前先选择预测。推荐选择“ H 打开多种结果，CX 改变两个比特的关联”。系统调用 `/api/inquiry`，返回两条线路的实际 counts、概率、比较报告和 replay request。

解释量子概念时使用最短版本：H（Hadamard gate）把 `|0⟩` 变成两个振幅的叠加，CX（controlled-X gate）在控制位为 1 时翻转目标位。完整 Bell 电路的 Z 基实验会集中观察到 `00` 和 `11`，但这一次实验不能单独证明 Bell 非定域性。

### 2:40—3:20　证据塔审计

带着护照向东前往证据塔。选择一个结论。系统会展示 supported、unsupported 或 inconclusive，并保留证据原因。

故意选择“CX 建立了最初的多种结果”也可以演示。案件仍能完成，但结论保持 `unsupported`。如果重新实验，旧审计会失效，说明游戏完成度和科学正确性是两件事。

### 3:20—4:20　五案地图

案件板从 `/api/story-world` 读取五案。第一案是《她的第八年》，随后是《第二个工牌》《潮线以内》《电网的夜班》和《证词校验器》。点击一个已开放案件，选择“运行最小对照实验”，前端会调用 `/api/compare`，显示首个分歧、分布距离和 scope boundary。

### 4:20—5:00　打开技术实验室

返回 `/`，展示 ProofTrace、Witness Chain、Hybrid path 和 RISC-V 证据。最后明确三条边界：故事不是科学证据，模拟器不是硬件，有限 Z 基相关性不是 Bell 非定域性证明。

## 现场备用路径

如果评委只剩一分钟，直接打开 `/`，在 ProofTrace 面板点击证明证书下载，再打开 `/game.html` 展示案件板和一案对照。全部本地运行，不需要 API Key、真机登录或网络服务。
